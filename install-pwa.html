Instalar Aplicación de Ventas

Instala la aplicación en tu dispositivo para acceso rápido y trabajo offline

1

Abre en navegador

Abre el sistema de ventas en Chrome, Safari o Edge

2

Busca opción de instalación

Busca el ícono de instalación en la barra de direcciones

3

Haz clic en instalar

Confirma la instalación cuando el navegador lo solicite

Instrucciones por dispositivo:

Android (Chrome):

1. Abre el menú (tres puntos)
2. Selecciona "Instalar aplicación"
3. Confirma la instalación

iPhone/iPad (Safari):

1. Toca el ícono de compartir
2. Desplázate hacia abajo y toca "Agregar a inicio"
3. Confirma con "Agregar"

Windows/Mac (Chrome/Edge):

1. Busca el ícono de instalación a la derecha de la barra de direcciones
2. Haz clic en "Instalar"
3. La aplicación se agregará a tu escritorio

Volver a la aplicación

La aplicación funciona completamente offline y tus datos se guardan localmente en tu dispositivo.
